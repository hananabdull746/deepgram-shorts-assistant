# ClipCue outcomes

- [x] **Ubuntu installation package** — Added an idempotent Ubuntu 22.04/24.04 installer and systemd unit. The installer creates a dedicated service account, persistent directories, protected environment file, Python virtual environment, installs FFmpeg/app dependencies, starts or restarts the loopback-only service, and checks `/health`. It generates admin/session secrets and leaves the Deepgram key for the operator to set. Shell syntax was checked; it has not been run against the user's VPS.
- [x] **Upload and transcribe authorized source media** — Authenticated upload streams to disk; unsupported, oversized, too-long, silent, and over-1080p media are rejected. A single background worker extracts low-bitrate audio with one FFmpeg thread and calls Deepgram Nova-3 with utterance timestamps. Transcript and candidate records commit atomically. Optional tokenized public callback mode supports longer asynchronous requests; synchronous mode supports tunnel-only setups.
- [x] **Review and refine moments** — Transcript and up to eight heuristic candidates are shown with editable titles and timestamps. Users can add custom moments under a total clip limit. Rendering is explicit; the user remains responsible for rights and final publication.
- [x] **Render and download Shorts** — Selected moments render to 720×1280 H.264/AAC MP4 with burned captions and SRT/VTT sidecars. Authenticated source and clip previews/downloads are available. Processing is serial; no auto-publishing is included.
- [x] **Secure access and recovery** — Administrator sessions, CSRF checks, a random callback token per project, callback body-size limits, loopback-only default binding, secret-free Git, and restart recovery are implemented. A successful transcript is not automatically resubmitted; interrupted transcription requires explicit retry.
- [x] **Documentation and tests** — Added setup/security docs, official Deepgram references, CI, and mocked API tests. Local validation: 13 tests pass; Python compilation and installer shell syntax pass; actual Uvicorn health/login checks pass; a real FFmpeg smoke render produced a 720×1280 MP4.

## Validation boundary

No Deepgram API key was available in this session, so tests mock Deepgram and no live/billable transcription request was made. The installer has not been executed on the user's VPS. Configure `DEEPGRAM_API_KEY` on the target server before use.
